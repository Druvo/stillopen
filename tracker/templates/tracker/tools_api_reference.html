The JSON API (/api/v1/)

This is the same API the signed-in app itself calls -- not a separate public API. Every request needs a signed-in session cookie plus a CSRF token, exactly like a normal browser visit; there is no API key for it, and a script running outside a browser session cannot call it. Another person's data is always a 404, never a permissions error that would confirm it exists.

MCP tools (/mcp/)

For AI assistants and automation (Claude Code, or any MCP client): a deliberately small, read-mostly tool list, authenticated with a personal token you make under Profile > Connect an AI assistant (read-only or read-and-change, with an expiry, revocable any time). No cookies are accepted here, so there is no CSRF exposure, and there is no delete tool and no way to read settings, keys or file contents.
